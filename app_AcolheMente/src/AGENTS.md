# AGENTS.md

## Contexto do projeto

Este repositório contém a aplicação AcolheMente. Mantenha as alterações focadas na solicitação do usuário e preserve as convenções existentes do projeto.

Comece pelo README.md para configurar o ambiente local, variáveis e fluxo de desenvolvimento.

## Arquivos principais

- `src/`: código-fonte da interface.
- `src/api/appClient.js`: cliente de comunicação com a API.
- `vite.config.js`: configuração do Vite.
- `.env.local`: valores locais apenas; nunca versionar segredos.

## Observações de trabalho

- Use `npm run dev` para desenvolvimento local do frontend.
- Prefira manter os contratos de endpoint do backend consistentes com o cliente atual.
- Antes de finalizar, execute os checks relevantes definidos em `package.json`.
